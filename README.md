# Prédiction du Churn Télécom avec le Dataset d'Orange Telecom

## Description
Ce projet vise à prédire le churn (départ des clients) dans le secteur des télécommunications en utilisant un ensemble de données fourni par Orange Telecom. En exploitant des techniques d'analyse de données et de machine learning, nous construisons un modèle prédictif permettant d'identifier les clients susceptibles de quitter leur opérateur.

## Objectifs
- Explorer et analyser les données clients pour identifier les facteurs influençant le churn.
- Nettoyer et transformer les données pour optimiser leur qualité et leur pertinence.
- Construire et comparer plusieurs modèles de classification (Random Forest, Logistic Regression, etc.).
- Optimiser les modèles pour améliorer la précision et la robustesse des prédictions.
- Visualiser les résultats et interpréter les facteurs clés de l'attrition client.

## Technologies Utilisées
- **Langages** : Python
- **Bibliothèques** : Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Outils de Machine Learning** : Random Forest, Logistic Regression, XGBoost
- **Environnement** : Jupyter Notebook


## Installation
1. **Cloner le projet**
```bash
git clone https://github.com/votre-repo/telecom-churn-prediction.git
cd telecom-churn-prediction
```
2. **Installer les dépendances**
```bash
pip install -r requirements.txt
```
3. **Lancer Jupyter Notebook**
```bash
jupyter notebook
```

## Utilisation
- Ouvrir et exécuter les notebooks dans `notebooks/` pour explorer les données et entraîner les modèles.
- Modifier les hyperparamètres dans `config.py` pour ajuster l'entraînement du modèle.
- Consulter `results/` pour visualiser les performances des modèles.
